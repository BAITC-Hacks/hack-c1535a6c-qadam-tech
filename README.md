# ToiTap — умный подбор event-подрядчиков

Хакатон-задача #79-lite (Qadam Tech). Заказчик указывает город, дату, тип мероприятия, категорию и бюджет (опционально длительность и язык), а сервис возвращает **до 3 подрядчиков**. У каждой карточки есть объяснение на фактах, почему подрядчик попал в выдачу. Если подходящих нет, причина объясняется словами.

**Стек:** FastAPI · pandas · OpenAI (опционально) · React 19 · TypeScript · Vite · Tailwind CSS

## Быстрый старт

Нужны Python 3.12+ и Node.js 22.12+.

```bash
# 1. Backend: http://localhost:8765 (Swagger: /docs)
cd backend
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env              # необязательно: впишите OPENAI_API_KEY
.venv/bin/uvicorn app.main:app --port 8765

# 2. Frontend: http://localhost:5173 (в другом терминале)
cd frontend
npm ci
npm run dev
```

Frontend проксирует `/api` на `localhost:8765` (`frontend/vite.config.ts`).

**Без OpenAI-ключа всё работает.** В этом случае объяснения строятся детерминированным шаблоном на фактах, а свободный текст разбирается правилами. С ключом их выполняет LLM (`gpt-4.1-mini`, `temperature=0`). При таймауте или ошибке LLM сервис автоматически возвращается к шаблону.

## Как устроен пайплайн

```text
текст ─► /api/parse ─► параметры ─► /api/search
                                      │
     1. Пул: категория × город ───────┤ пусто → outcome "no_category_in_city"
     2. Жёсткие фильтры ──────────────┤ занят на дату · цена > бюджета · формат · язык · max_hours
        (у каждого отсеянного —       │ никто не прошёл → outcome "no_match" + разбивка причин
         список причин)               │
     3. Ранжирование (детерминировано, tie-break по id):
        3·опыт формата в описании + 1·надёжность профиля + 1.5·запас бюджета + 0.5·язык + 0.5·часы
     4. Объяснение топ-3: факты (цена vs бюджет и соседи, свободная дата, языки, часы)
        + цитата из описания → LLM (или шаблон) → outcome "found"; если < 3 — сказано почему
```

| Требование | Где реализовано |
| --- | --- |
| Занятый на дату подрядчик не попадает в выдачу | `backend/app/search.py` → `rejection_reasons` |
| Три различимых исхода | поле `outcome` + `message` в ответе, отдельные заголовки в UI |
| Меньше трёх — объяснить почему | `message`: «Меньше 3, потому что: 5 — заняты на 16.10…» |
| Детерминизм | сортировка `(-score, id)`, LLM `temperature=0` + кэш по запросу |
| Объяснения не взаимозаменяемы | цифры конкретного профиля, сравнение с соседями, цитата из его описания |
| Реальный профиль vs синтетический | флаг `is_synthetic`, бейдж на карточке |
| `max_hours = null` | не ограничивает длительность (флорист, декоратор, сувениры) |

## Демо-сценарии (Definition of Done)

`cd backend && .venv/bin/python demo.py` прогоняет их через API:

| Сценарий | Запрос | Результат |
| --- | --- | --- |
| Плотная категория, осень | Ведущий · Алматы · 15.10 · свадьба · 1,5 млн | 3 из 5 подходящих |
| Та же, другая дата | … · 16.10 | 2 карточки, «5 — заняты на 16.10.2026» |
| Редкая категория | Флорист · Алматы · 14.11 · 500 тыс | 1 карточка, второй флорист занят |
| Нет категории в городе | Декоратор · Астана | «Эта категория есть в: Алматы» |
| Никто не проходит | Банкетный зал · Алматы · 26.12 · конференция · 200 тыс | разбивка: бюджет / занятость / формат |

## Структура

```text
backend/
├── app/
│   ├── main.py          # FastAPI: /api/search, /api/parse, /api/facets, /api/health
│   ├── data.py          # CSV → pandas → JSON-кэш
│   ├── search.py        # пул, фильтры, причины, скоринг, исходы
│   ├── explain.py       # шаблонные объяснения + выбор цитаты из описания
│   ├── llm.py           # мост к AI-модулю: evidence, fallback, кэш
│   ├── rules_parser.py  # разбор текста без LLM
│   └── ai/              # OpenAI: промпты, парсер запроса, генератор объяснений
├── data/dataset.csv     # 66 профилей (анонимизированный датасет)
├── tests/               # pytest: пайплайн, исходы, LLM-fallback, AI-модуль
└── demo.py
frontend/
└── src/
    ├── main.tsx         # UI: поиск, карточки, исходы, отсеянные, избранное, темы
    ├── api.ts           # контракт backend + помощники
    └── api.test.ts
```

## Команда

- **Backend и данные:** FastAPI, фильтрация, ранжирование, исходы
- **AI:** промпты, разбор запроса, LLM-объяснения (`backend/app/ai`)
- **Frontend и Git:** интерфейс ToiTap, интеграция

Не входит в MVP: бронирование, уведомления подрядчикам, дообучение моделей.
