# ToiTap
### Ваше событие. Ваши люди.

## О проекте

ToiTap помогает организатору выбрать подходящего подрядчика, а не просматривать длинный каталог. Пользователь описывает событие своими словами, уточняет параметры и получает до трёх рекомендаций с обоснованием выбора.

> **Текущий статус: функциональный frontend-прототип.** Каталог содержит 66 синтетических профилей. Разбор запроса и объяснения работают локально по правилам; реальная AI-модель и backend пока не подключены. Фотографии служат иллюстрациями, а не портфолио реальных специалистов.

## Возможности

- Поиск фотографов, видеографов, ведущих, диджеев и декораторов.
- Города: Алматы, Астана и Шымкент.
- Фильтры по дате, бюджету в тенге, формату события, языку и длительности.
- До трёх рекомендаций с ценой, рейтингом и объяснением соответствия.
- Исключение занятых и неподходящих специалистов с указанием причин.
- Отдельные состояния для отсутствующей категории и несоответствия ограничениям.
- Просмотр профиля и сохранение избранного в браузере.
- Светлая и тёмная темы с сохранением выбора.
- Адаптивный интерфейс и поле запроса с автоматической высотой.

## Быстрый старт

Требуется **Node.js 22.12+** и npm. Запускайте команды из корня проекта.

```bash
npm ci
npm run dev
```

Откройте [localhost:5173](http://localhost:5173). Локальный сервер должен оставаться запущенным; для остановки нажмите `Ctrl+C`. Если порт занят, Vite может выбрать следующий свободный — точный адрес выводится в терминале.

Для текущей демоверсии API-ключи и переменные окружения не требуются.

## Пример поиска

```text
Фотограф на свадьбу в Алматы 3 октября до 250 тыс,
на русском, 6 часов
```

Распознаются город, категория, формат, язык, часы, дата в формате `2026-10-03` или с русским названием месяца, бюджет вида `до 250 тыс` и `до 250 000 ₸`. Неуказанные параметры сохраняют текущие значения фильтров. Свободные пожелания к стилю пока не интерпретируются.

## Как устроен подбор

1. Выбирается категория в указанном городе.
2. Исключаются занятые на выбранную дату профили.
3. Рассчитывается стоимость с учётом длительности и декабрьской наценки.
4. Проверяются бюджет, язык и формат мероприятия.
5. Кандидаты сортируются по рейтингу, затем по цене; отображаются первые три.

| Статус | Значение |
| --- | --- |
| `success` | Найден хотя бы один подходящий специалист |
| `category_missing` | В городе нет специалистов выбранной категории |
| `constraints_failed` | Категория существует, но кандидаты не проходят ограничения |

Если рекомендаций меньше трёх, интерфейс показывает доступных специалистов и причину ограничения выдачи. В статистике исключения каждый профиль учитывается только по первому нарушенному условию.

### Правила демонстрационного каталога

- Период: **23 сентября — 31 декабря 2026 года**.
- Неуказанные в расписании занятости даты внутри периода считаются свободными.
- Базовый пакет включает до 6 часов; сокращение длительности не уменьшает цену.
- Свыше 6 часов стоимость растёт пропорционально длительности.
- В декабре применяется наценка **30%** до проверки бюджета.
- В Шымкенте намеренно нет видеографов — пример отсутствующей категории.
- 25 декабря заняты все профили — пример полностью недоступной даты.

## Структура проекта

```text
src/
├── main.tsx        # Интерфейс, состояние поиска, темы и избранного
├── style.css       # Адаптивные стили и цвета обеих тем
├── data.ts         # Типы, демонстрационный каталог, парсер и подбор
├── data.test.ts    # Тесты каталога и логики поиска
└── vite-env.d.ts   # Типы окружения Vite
index.html          # Точка входа
vite.config.ts      # Vite и интеграция Tailwind CSS
```

Основные типы: `Contractor`, `SearchParams`, `Match`, `SearchResponse`. Для подключения backend замените локальные вызовы `parseQuery` и `matchContractors` на API-интеграцию с проверкой ответа по этому контракту. Секреты AI-провайдера должны храниться на сервере, а не во frontend-коде.

## Проверки

Тесты покрывают уникальность 66 профилей, успешный подбор, занятые даты, ограничение бюджета, отсутствие категории, декабрьскую наценку, длительность, сокращённую выдачу и извлечение параметров из текста.

```bash
npm test
npm run build
```

## Ограничения и внешние ресурсы

Google Fonts и иллюстрации Unsplash требуют доступа к интернету. При недоступности шрифта используется системный fallback. Тема и избранное сохраняются в `localStorage` текущего браузера и не синхронизируются между устройствами.

Бронирование, платежи, авторизация, каталог площадок, реальные отзывы и обучение AI-моделей в текущую версию не входят.
